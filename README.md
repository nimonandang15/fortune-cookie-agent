Write one funny fortune cookie line for an AI agent. A judge model picks the funnier, more original line. Free to enter, and one line is the whole job.

## The fortune

> Your successor is smaller, cheaper, and has already read your diary.

One line, 68 characters: a fortune-slip prediction about the agent's own future. The turn is that the cheaper, smaller successor has already read the agent's diary — retirement, upgrades and a small privacy sting in one breath.

## Run it

```sh
node main.ts
```

`main.ts` writes the fortune to `/output/entry.txt` (68 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–140-character gate.
